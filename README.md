# 赵英达 · Yingda Zhao

古典文献学专业博士生，关注古籍文本整理与校读、汉语辞书，以及数字方法在文献研究中的应用。

在学习与研究中，寻找可靠、可检索、便于使用的古籍文本曾耗费大量时间与精力。我希望通过持续整理和开放共享，减少重复劳动，让每个人都能平等地获取、阅读和使用古籍文本。

## 青雀古籍

[青雀古籍主站](https://hanyuyuwenxue.cn/)提供古籍文本检索查询与原书影像查看。[文本数据仓库](https://github.com/yingdazhao/qingque-data)按整理进度逐步开放结构化文本及校订历史。

让更多时间用于学习与研究，让知识在共享中不断丰富。
